Smart PC Store – Project Report

1. Project Introduction

Smart PC Store is a web-based platform designed to help users explore computer components, compare products, and build compatible PC systems.

2. Project Goals

- Display computer components and their specifications.
- Help users select compatible PC parts.
- Provide prebuilt PC configurations.
- Allow users to compare products.
- Provide price history information.

3. Data Structure

The project uses JSON files to organize its data:

- "products.json": Product information and specifications.
- "prebuilt-systems.json": Preconfigured PC systems.
- "categories.json": Product categories.
- "price-history.json": Historical product prices.
- "compatibility-rules.json": Component compatibility rules.

4. Assets Structure

The assets directory contains:

- Product images
- Website banners
- Icons
- Fonts

5. Documentation

The docs directory contains project documentation and wireframes.

6. Project Status

The initial directory structure and data files have been created. Further implementation and integration will be completed by the project team.
